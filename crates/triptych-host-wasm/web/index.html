        Click or tap the terminal before typing. On mobile, use the terminal
        keys for Ctrl, Esc, Tab, and arrows. Return sends CR; paste converts
        line endings for CP/M. A CP/M flush followed by “Working disk saved”
        makes guest writes reload-safe. Download saved disk copies the committed
        browser image. Download latest checkpoint can recover newer
        guest-flushed data after a save failure; it may not be durably saved.
        Later unflushed writes and unsaved editor text are excluded. Browser
        storage may be cleared or evicted: keep downloaded backups too.
      

    

    
      

        
Files and recovery

        
      

      

      

      
      

        
        
        
      

      

        Guest stuck or disk will not boot?
        

          Recovery starts from the last saved disk without saving the running
          guest. Download its latest checkpoint first if you need to keep it.
          Applying a replacement preserves the saved disk as a backup, but
          discards guest RAM and any changes not saved in browser storage.
        

        
        
      

      
Files on the committed disk (user 0)

      
    
      
      
    
        Use CP/M 8.3 filenames. Empty imports and read-only replacements are
        rejected. A batch is applied in full or not at all. Downloads retain
        128-byte record padding.
      
    
      
    Development tools
    
      
      
      
      Nucleus source project
      
      
      
        Edit the separate source files, save and exit, then prepare their
        single-file build input here. Apply and restart before running
        NUC GAME.NU, then GAME. This is host-assisted
        packaging; the released CP/M compiler still reads one input file.
      
      
      
      
      
        
        
      
      
      
      
        Preparation stages the generated source and its source map together.
        Source order comes from the project file; import comments are not
        resolved.
      
      
      
      
      
      
        The original diagnostic is preserved. Mapping requires unchanged saved
        source and build bytes; it does not describe unsaved editor text.
      
      
      
      Disk capacity
      
      
      
      
        Upgrade a legacy disk while preserving files in all user areas. Apply or
        cancel other pending changes first. Applying the upgrade replaces the
        resident system, restarts CP/M and backs up the complete old disk. This
        profile supports drive A only; additional drives are not enabled.
      
      
      
      Whole-disk replacement
      
      
      
      
      
        Leave adaptation unchecked for exact recovery. Applying a disk, files or
        tools preserves the previous committed disk as a backup.
